# Decorations

Render-only scenery (plants, rocks, torches, crystals…): the level JSON key `foliage`. A type is a file in
`src/world/decorations/types/` (it may return a LIST: the themed sets) registered in
`src/world/decorations/Decorations.lua`; shared drawing / animation / particle helpers in
`src/world/decorations/DecoFx.lua`. Sprites in `assets/images/world/decorations/<theme>/` from
`tools/art/world/make_decorations.py` and `make_biome_art.py`. Every type: [reference/decorations-and-modes](../reference/decorations-and-modes.md).
Decorations must stand on THEIR material (no plants on rock): `retheme.py --decor` audits it.

## Details

Render-only (client + editor; the server builds them but never draws). `placement` = 'sub'
(sprite 8 art px wide = 32 px, anchored bottom-centre of the quarter) or 'cell' (16 px wide
= 64, bottom-centre of the cell; taller ones grow upward); hanging ones draw from the TOP of
their cell/quarter (`DecoFx.sheet(..., {hang=true})`). A type file may return a LIST: themed
sets `ice_set` (Hielo y nieve), `cave_set` (Cueva), `water_set` (Acuático), `tropical_set`
(Tropical) + `icicle`, `palmtree` (Tropical), `meadow_set` (Pradera), `volcano_set` (Volcán), `fortress_set`
(Fortaleza), `jungle_set` (Jungla), `tulip`/`stretch` (Plantas); palette order
`DecorationTypes.CATEGORIES`. `src/world/decorations/DecoFx.lua` = shared helpers: sprite
strips at ×4, `wave` (row-by-row sine sway, root still), additive `glow`, per-decoration
particles in `d.fx` (`emit/update/draw`, spawned only while seen, `every` timers), `drip`
(forms, falls, splashes on `d.level:landingCross`); bubbles pop out of water. Sprites:
`assets/images/world/decorations/<theme>/` + `fx/` from `tools/art/world/make_decorations.py` (simple
style: 1-px dark outline + 3 tones, no noise; never overwrites; `--force [names]`). Every
sprite gets a 1-px transparent margin (sides + top, or bottom if it hangs) with its outline
closed there, and `edge_check` warns if fill touches the canvas edge (it looked CUT in
game); `DecoFx.strip(path)` without a frame width = the whole image. It also
REDESIGNED the old foliage (tulip, stretch, palmtree parts) in that style from the user's
originals (kept outside the repo); the icicle now uses `decorations/ice/icicle.png` (the user's
original `icespike.png` is kept outside the repo). Showcase arena `tools/levelgen/arenas/decoraciones.json`
(`run.sh editor_open PLAY=...`), generated by `tools/levelgen/arenas/make_decoraciones.py`: one strip per category,
each on its island's ground (10 rows of air: the big trees fit), hanging ones at the end of the strip from its
ceiling. The list comes from `docs/reference/decorations-and-modes.md` (written by the game), so after adding a type:
`run.sh docs_reference` → `make_decoraciones.py` → `run.sh level_shots SCALE=0.35 -- tools/levelgen/arenas/decoraciones.json`.

## Big trees and the jungle set (0.5.83)

- **`tools/art/world/make_big_trees.py --apply`**: big trees (5-8 tiles tall) and extras for every island, added to the
  existing sets with NEW names: `meadow_set` big_oak, big_birch, big_fir, hazel_bush, stump, boulder, lupines;
  `tropical_set` coconut_palm, twin_palm, young_palm (three layers of the same size, `trunk` / `coconuts` / `fronds`,
  in their own animation set `world/decorations/tropical/<name>`; waved with the same rhythm so they stay joined, the
  fronds a bit more; `baseDx` moves a leaning palm so its foot is on its cell), beach_grass, driftwood, beach_rocks;
  `ice_set` snowy_fir, snowy_fir_small (snow falls from the branches), snow_rock, snow_stump, winter_grass;
  `volcano_set` dead_tree (glowing cracks, embers, light), charred_stump (smoke), obsidian_shards, burnt_shrub;
  `cave_set` giant_mushroom, giant_mushroom_violet (cap glow, light, falling spores), mushroom_cluster, hanging_roots,
  cave_boulder; new `fortress_set` old_tree, cypress, banner (hangs and flutters), ivy_hang, broken_column, urn.
- **`tools/art/world/make_jungle_decor.py --apply`**: `jungle_set` (category Jungla): ceiba (8 tiles) and
  strangler_fig (6) in two layers (`_trunk` still, `_canopy` waves; leaves fall to the ground), banana_plant,
  tree_fern, heliconia (pollen), elephant_ear, jungle_fern, ruined_arch (drips), broken_pillar, stone_idol (eyes pulse,
  teal light), fallen_block, stone_brazier (fire, light, embers, `fireCrackle` every 2-4 s), mossy_log (spores), roots,
  mud_puddle (bubble, mist), liana_long / liana_mid / liana_short, hanging_moss (drips), flower_vine, hanging_orchid,
  bromeliad, orchid, jungle_mushrooms (glow), dragonfly (hovers and darts around its cell: a pure function of time),
  fireflies (pulsing lights, no particles state). Particles `fx/jungle_leaf`, `firefly`, `pollen`, `mist`, `drip`
  (`drip` + `drip_splash` for `DecoFx.drip(d, x, y, color, drop, splash)`).
- Both generators register what they apply as named animations (`add_anims` in `tools/anim/common.py`: adds the
  missing ones, never touches an existing one).
- **Culling**: `Level:renderDecorations` skips a decoration whose ANCHOR is more than `cullMargin` tiles (default 4)
  off-screen. A big tree sets `cullMargin` = its height in tiles + 2 (ceiba 10), or its top would pop in while its
  foot is still below the screen. All big trees are `layer = 'back'` (behind the player and enemies).
- **Cost**: `DecoFx.wave` draws runs of art rows with the same offset as ONE band (one shared Quad moved with
  `setViewport`, nothing created per frame): a 129-row tree is a handful of draws, not 129. `perf` on the showcase
  arena: 105 draw calls, 6.9 KB garbage per frame, 0 resources created.
- Editor thumbnails: `editor.previewScale` fits the big trees in the palette cell (≈0.12); `editor.previewLift` raises
  what hangs more than its cell so the thumbnail shows it whole.
- `DecoFx.leaf(d, x, y, sheet)`: a leaf from a canopy (from a tall one it falls faster and lives longer: it reaches
  the ground). `DecoFx.sheet(..., { hang = true, rot = r })` turns around the top.
