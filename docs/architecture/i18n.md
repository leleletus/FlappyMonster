# Languages (i18n)

Every text the PLAYER sees is translated (Spanish and English today) and resolved at draw time; the level editor is a
development tool and stays in Spanish; code comments are in Spanish.

**Files:** `src/core/Lang.lua` (lookup, interpolation, server messages, level and boss names, the CSV reader),
`assets/lang/translations.csv` (THE texts: one spreadsheet, a row per text, a column per language),
`src/core/Settings.lua` (the chosen language, in `options.cfg`), `src/ui/PixelFont.lua` (big menu text).
**Harnesses:** `lang_names`; `project_check` (`idiomas`) fails when a key has no text in some language or a key
appears twice.

**To add a text:** a row in `translations.csv` (key + every language column) and `L('section.key', { var = … })`.
**To add a language:** a new column whose header is its id (`fr`) + one entry in `Lang.LANGUAGES`. Unused keys are
dead weight: the audit of 2026-10-07 removed eight.

## The translation sheet (2026-11-04, the user's request)

`assets/lang/translations.csv` is edited by hand by the user (LibreOffice Calc / Excel / Google Sheets) and by
developers: change a cell, save as CSV, the game reads it at start. Columns: `key` · one per language id (`es`, `en`)
· `notes` (help for translators, ignored by the game; any column whose header is not `key` or a language is ignored).

- Format: UTF-8 (a BOM is accepted: Excel writes one), comma-separated; quoted cells may hold commas, `""` quotes and
  real line breaks. If the first line has no comma but has `;` (Excel in Spanish saves like that) `;` is the separator.
- `\n` inside a cell is a line break (the converted texts use it); `\\` is a backslash.
- An EMPTY cell in a non-Spanish column = no translation → the Spanish text is shown. An empty Spanish cell is an
  intentionally empty text. Rows with no key or a key starting with `#` are skipped (use them as separators).
- Row order is free; the file keeps the old grouping by screen (`common`, `hud`, `menu`, `hub`, `room`, `daily`…).
- Keys are ids used in code (and some, `srv.*`, in network messages): rename a key only together with its uses.
- Before 0.5.160 the texts were two Lua tables (`es.lua`, `en.lua`); they were converted 1:1 (1180 values compared)
  and deleted. Their few comments went to the `notes` column.

## Details

- `src/core/Lang.lua`: `local L = require 'src/core/Lang'` → `L('hub.create')`,
  `L('mode.hunt.left', { n = 3 })` (`{var}` interpolation). Missing key → es →
  the key itself. Files with a local `L` layout table (OnlineRoomState,
  OnlineLoginState, Notify) import it as `Lang`.

- Texts: `assets/lang/translations.csv` — keys grouped by screen (`common`,
  `hud`, `menu`, `hub`, `room`, `daily`, `oadv`, `results`, `msm`, `mode`, `srv`, `boss`,
  `notify`, `err`...). Every key needs a cell in EVERY language column.

- Translate at DRAW time: option lists store keys (`LIST_BTNS`, pause opts,
  `PMENU_LABELS`) and draw `L(key)`; layouts must measure the real text
  (`fitText`, `FONT:getWidth(L(..))`) — English/Spanish differ in length.

- Modes: text fields are keys `mode.<id>.label|tagline|objective|empty_hint`
  resolved on read by `ModeTypes` (`m.label` is already translated).
  `reasonText(reason)` and `rank` notes return KEYS; `Modes.reasonText(mode,
  reason)` translates. Boss names: `boss.<type>` (every boss type in EVERY language column); a level can
  give one boss its OWN name like level names — props `title` (Spanish) / `title_en` (`title_<lang>`), editor
  group "Nombre" of every boss (`Boss.props`); `Lang.bossName(type, props)` = custom name in the current language
  (no title_en → the Spanish one) or the type's translated name; used by `Boss:title()` (bars, intro cinema) and
  Free Play cards (`LevelCatalog` `info.bossNames`). Harness `lang_names` (also warns about levels without name_en).

- Server messages: `Lang.message(key, args, extra)` → `{key, args, msg(es)}`;
  clients show `L.fromServer(data, fallbackKey)` in their own language.
  `round_end` carries `reason` + `noteKey` (plus Spanish text for old clients).
  Lang reads the sheet with `love.filesystem.read` (the server patches it).

- `src/core/Settings.lua`: player options saved as `options.cfg` in the save dir
  (NEVER a name like settings.lua: the save dir shadows the game's modules).
  `SettingsState` = language selector (main menu → CONFIGURACIÓN).
  `options.cfg` also keeps `onlineName` = the last name the server accepted (`Settings.setOnlineName`, saved on
  `login_success`): the online login field comes PREFILLED with it (3.66.3).

- Level names: JSON `"name"` (Spanish) + `"name_en"` (+ `name_<lang>` for new languages);
  show them with `Lang.localName(t)` (FreePlay cards, mode menu, online room; the server sends
  `name_en` / `levelName_en` too). Editor: Nivel → General → "Inglés".

- Big menu buttons are TEXT drawn with `src/ui/PixelFont.lua` (the 5-px font of
  the old button images, accents included): `PixelFont.draw(text, x, y, scale,
  alpha)`, `.width`, `.height`. No text baked into images.

- Key placeholders (0.5.10): `Lang.autoArgs` (set by game.lua to `Input.hints`) fills the placeholders a call does not
  pass, so hint texts are written as `"{arrows} elegir    {ok} jugar    {back} volver"` and show the keys of the device
  in use. Never write a key name (`[ENTER]`, `[ESC]`...) inside a text: use the placeholder.
